## Development Approach
**Discover & specify:** Clarify users, constraints, functional/non-functional requirements, user stories, and testable acceptance criteria.
**Design:** Plan modular responsibilities, data models, API contracts, permission boundaries, failure states, and architecture tradeoffs.
**Implement:** Work in small Git changes; give agents relevant context, bounded tools, and explicit tasks. Review generated code and keep secrets outside prompts.
**Verify:** Use appropriate unit, integration, and browser checks. Assess accessibility, authorization, AI grounding, structured outputs, and fallback behavior.
**Release:** Validate configuration, migrations, automated checks, deployed workflows, and rollback options.
**Maintain:** Use feedback and error/performance signals to prioritize fixes; update documentation and dependencies. Develop retrieval evaluation skills while considering AI quality, latency, and cost.
